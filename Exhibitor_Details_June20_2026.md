### Product 1 — ARC PEM (Project Expense Manager)
> **India's Complete Construction Finance Platform**

ARC PEM is a fully offline desktop software platform built exclusively for Indian construction firms and architecture consultancies. It unifies Bill of Quantities (BOQ), vendor billing, labour tracking, contractor ledgers, GST reconciliation, and financial reporting into a single integrated solution — replacing disconnected Excel sheets, Tally manual entries, and WhatsApp coordination.

**Platform:** Windows Desktop (100% Offline)
**Current Version:** v2.0.1
**Customers:** 30+ architecture studios and construction firms across India

#### Core Capabilities

| Module | What It Does |
|---|---|
| **BOQ Builder** | Structured line items with colour-coded categories (Civil, MEP, Finishing, Landscaping), live cost computation, GST auto-calculation (18%), cost-per-sq.ft |
| **Expense & Vendor Ledger** | Vendor bills with GST toggle (CGST/SGST), advance/cash/cheque/pending payment tracking |
| **Labour Tracking** | Daily headcount and skill-wise breakdowns, PDF attendance import |
| **Contractor Management** | Running bills, retention tracking, contractor ledger |
| **GST Register** | Auto-generated monthly GST Purchase Register |
| **Tally Export** | Tally ERP 9 / Tally Prime CSV export — eliminates manual CA re-entry |
| **Reporting** | PDF/Excel exports, pending payments dashboard with overdue alerts |

#### Key Differentiators

### Product 2 — Keystone
> **The Platform That Holds Your Firm Together**
> *Employee & Project Management for Architecture and Construction Firms*

Keystone is a cloud-based enterprise management platform built for architectural and construction consulting firms. It serves as the central hub for employee operations, project tracking, attendance, daily reporting, site supervision, and payroll — accessible from any browser and installable as a Progressive Web App (PWA) on mobile.

Originally built for a leading architecture consultancy, Keystone is now available as a standalone product for all firms that need a professional, field-ready management system.

**Platform:** Web Application (Cloud-Hosted, PWA-enabled)
**Access:** Browser + Mobile (Android/iOS installable)
**Built With:** Next.js, PostgreSQL, Google Maps API

#### Core Modules

| Module | What It Does |
|---|---|
| **Attendance Management** | GPS-verified digital check-in/check-out, monthly calendar view, overtime tracking |
| **Project Management** | Create/manage projects with milestones, deliverables, client details, and team assignment |
| **Daily Reporting** | Employees submit daily task reports with photos; managers review, comment, and sign off |
| **Site Supervision** | Site supervisors log daily labour counts (Masons, Coolies, Helpers), shift-wise, with voice notes and photos |
| **Leave Management** | Full/half-day/hourly/exam leaves, approval workflow, balance tracking, auto-approval rules |
| **Salary & Payroll** | Salary structure setup per employee, payslip generation (PDF), deductions, advances, incentives |
| **Employee Directory** | Complete profiles with skills, Aadhar/PAN, contact info, role-based access |
| **Notice Board** | Priority-based internal communications with WhatsApp distribution |
| **Recognition** | Employee of the Month program with monthly history |
| **Compliance Tracking** | Missed report alerts, attendance regularisation, leave adjustments |

#### User Roles Supported
Principal Architect / Admin · Senior Manager · Junior Architect · Site Supervisor · Site Engineer · Trainee / Intern · Non-Technical Staff

#### Key Differentiators
- **GPS Geolocation Verification** — prevents proxy attendance; captures location on check-in and site visits
- **Voice-to-Text Input** — audio notes for site logs and daily reports
- **Progressive Web App** — installable on mobile, works like a native app
- **Automated Payroll** — salary slip generation with leave deductions and overtime adjustments
- **Labour Report Export** — PDF export of labour counts by period, ready for billing
- **Role-Based Dashboards** — every user sees exactly what they need based on their role
- **Site Photo/Video Documentation** — on-ground evidence uploaded directly from site visits

#### The Name
The **keystone** is the central wedge-shaped stone at the crown of an arch — the piece that locks every other stone in place and makes the structure hold. Keystone, the product, is exactly that for your firm: the central platform that connects your people, projects, and operations so everything holds together.
